# Results

This folder contains the main tables and figures for the final report. Supporting outputs are in `archive/`.

## Tables

- `tables/demand_recovery_summary.csv`: demand-recovery summary.
- `tables/ppo_original_vs_balanced_comparison.csv`: PPO comparison before and after balanced training.
- `tables/final_heldout_baseline_ladder.csv`: full 13-policy held-out baseline ladder.
- `tables/dqn_heldout_test_summary.csv`: locked DQN held-out result.
- `tables/final_profit_waste_pareto_frontier.csv`: profit-waste comparison.

## Figures

- `figures/01_observed_vs_recovered_demand.png`: observed versus recovered demand.
- `figures/02_recovered_demand_adjustment_distribution.png`: recovered-demand adjustment scale.
- `figures/03_original_vs_balanced_ppo_error_decomposition.png`: PPO redesign error decomposition.
- `figures/04_ppo_action_collapse_diagnostic.png`: zero-action collapse diagnostic.
- `figures/heldout_policy_comparison.png`: held-out profit across all 13 policies.
- `figures/06_learned_policies_vs_fixed_markdown.png`: learned policies versus fixed markdowns.
- `figures/07_profit_waste_pareto_frontier.png`: profit-waste frontier.
