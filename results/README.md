# Teacher-Facing Results

This folder keeps the compact result set used by the final report. Full supporting material is retained under `archive/`.

## Key Tables

- `final_summary.csv`: one-screen summary of the final conclusion.
- `key_tables/final_method_comparison.csv`: final candidate comparison.
- `key_tables/final_heldout_baseline_ladder.csv`: secondary descriptive baseline ladder.
- `key_tables/ppo_original_vs_balanced_comparison.csv`: PPO redesign comparison.
- `key_tables/dqn_validation_summary.csv`: DQN validation behavior.
- `key_tables/dqn_heldout_test_summary.csv`: locked DQN held-out result.
- `key_tables/demand_recovery_summary.csv`: recovered-demand summary.
- `key_tables/final_profit_waste_pareto_frontier.csv`: profit-waste frontier.
